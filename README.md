# Hutly — Real Estate Landing Page

Hutly is a modern real estate landing page designed to present properties, customer reviews, services, and contact information through a clean and visually focused interface.

The project focuses on creating a premium real estate experience with a structured layout, large typography, rounded sections, and a consistent visual style.

## Live Demo

https://ezz08.github.io/Hutly/

## Overview

Hutly was built as a front-end practice project based on a modern real estate landing page design.

The website includes multiple sections that guide visitors through the brand introduction, property information, customer reviews, available services, and a final call-to-action.

The design uses a dark navy and light-gray color palette combined with rounded containers and large typography to create a modern real estate aesthetic.

## Features

* Responsive real estate landing page structure
* Navigation bar with smooth section navigation
* Hero section with property-focused introduction
* Property information section
* Customer reviews section
* Services section
* Call-to-action footer
* Smooth scrolling between sections
* Interactive hover effects
* Consistent typography and spacing
* Modern rounded-card design

## Sections

### Header

The header contains:

* Hutly logo and brand name
* Navigation links
* Contact Us button

### Hero Section

The hero section introduces Hutly with:

* Capital raised statistic
* Main headline
* Supporting description
* Property image
* Introduction statement
* Start Exploring call-to-action

### Properties

The properties section presents the platform's focus on creating personalized living spaces.

It combines a large property image with supporting statistics, descriptive content, and a See More button.

### Customer Reviews

The reviews section showcases customer feedback using multiple review cards.

Each card includes:

* Customer testimonial
* Customer name
* Star rating

### Services

The services section highlights the main services offered by Hutly:

* Furniture Design
* Interior Details
* Home Revamping

Each service contains a short description explaining its role in creating a more comfortable and visually appealing living environment.

### Footer

The footer provides a final call-to-action with:

* Project introduction
* Contact Us option
* Hutly branding
* Navigation links

## Design

The design follows a modern real estate visual language with:

* Dark navy `#050F27`
* Light gray `#F7F8F8`
* Large typography
* Rounded corners
* Spacious layouts
* Minimal visual elements
* Card-based content sections

The website primarily uses the Poppins font family for its typography.

## Getting Started

To run the project locally:

1. Clone the repository.

```bash
git clone https://github.com/Ezz08/Hutly.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional dependencies or installation steps are required.
